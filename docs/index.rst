suncast
=======

suncast is a camper solar forecast service for the buspi Raspberry Pi: a small web app that
shows an hourly and daily PV forecast on a map, and corrects it with a factor learned from
the charger's own history. These pages cover running it, the facts to look up, and why it is
built the way it is. The README is the short entry point; this site is the detail.
